# Module 04 Overview: Forms

## Topic area

Collect user input first with template-driven forms and then with reactive forms.

## Prior modules

Modules 01-03.

## Angular v15, React, and Vue framing

Angular v15 used both template-driven and reactive forms too, but modern lessons pair them with standalone imports and the new control-flow syntax. React learners can compare FormControl with controlled input state. Vue learners can compare ngModel with v-model, then see reactive forms as a more explicit model.

## Micro-lessons

- 04-01 Replace the manual input binding with ngModel: template-driven forms with FormsModule and [(ngModel)].
- 04-02 Introduce a single reactive FormControl: FormControl as the model for one field.
- 04-03 Add a required validator: Validators.required and invalid state.
- 04-04 Show validation feedback after touch: touched state plus @if error rendering.
- 04-05 Combine controls into a FormGroup: FormGroup with formGroup and formControlName.
- 04-06 Submit the form and append a topic: ngSubmit and immutable signal append in the dashboard.
